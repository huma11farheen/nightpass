# 10 · Copy & Voice

## Voice traits

| Trait | Description |
|---|---|
| **Direct** | Short sentences. Active voice. No hedging. |
| **Editorial** | Mix of mono fact-statements and italic-serif aside. |
| **Cool, not warm** | Confident, never trying to be your friend. |
| **Concrete** | Times, prices, capacities, names. No vague vibe-words. |
| **Local** | References specific places, DJs, neighborhoods. |

## Tone matrix

| ❌ Avoid | ✅ Use |
|---|---|
| "Welcome back!" | "Back already." |
| "Oops, no events found." | "Nothing tonight." |
| "Get your tickets now!" | "Buy · ¥3000" |
| "🔥 Selling fast!" | "62% gone" |
| "We're so excited to..." | "Out 22:00 · doors 23:00" |
| "Loading..." | "..." or `▸▸▸` |
| "Almost there!" | "1 of 2" |

## Capitalization

- **Sentence case** for body, button labels (when not mono).
- **UPPERCASE + tracked** for mono chrome labels and tickers.
- **lowercase** for editorial italic accents ("feat. honey dijon").
- **Title Case** is forbidden everywhere except proper nouns.

## Punctuation

- Use `·` (middle dot) as a separator, not `|` or `,`. Example: `SAT · 25 · ¥2000`.
- Use `→` instead of `>` or `->`.
- No exclamation marks. None. Ever.
- Em-dash `—` for asides. No double-hyphens.
- Time format: 24-hour (`22:00`, not `10pm`).

## Common copy patterns

### Status labels
```
LIVE · 124 INSIDE
TONIGHT · 14 OPEN
SOLD OUT
DOORS 22:00
LATE — UNTIL 06:00
```

### Event meta line
```
SAT · 25 APR · BAIA SHIBUYA · ¥2000
```

### Featured tag
```
★ FEATURED       (mono on acid block)
◉ LIVE NOW       (mono on neon block)
```

### Editorial accent (Fraunces italic)
```
feat. honey dijon
a night by audio garden
in conversation with saoirse
```

### Empty states
```
Nothing tonight.
Try tomorrow.
```
Not: "We couldn't find any events. Please try a different filter!"

### Errors
```
Couldn't load.
Tap to retry.
```
Not: "Oops! Something went wrong."

### Confirmation
```
Ticket secured.
Sent to your inbox.
```
Not: "🎉 Yay! Your ticket is on the way!"
